## What is Cloud Computing

### 0.1 What Is Cloud Computing?

### Let’s start with the simplest possible definition

**Cloud computing means:**

> Using someone else’s computer over the internet instead of using your own computer.

That’s it.  
No magic. No buzzwords. No complexity (yet).

---

#### A real-life analogy 

Imagine this:

- You want to store photos
- You can:
  - Save them on your **phone**
  - Or save them on **Google Drive**

When you use Google Drive:
- The photos are **not on your phone**
- They are stored on **Google’s computers**
- You access them using the **internet**

That is **cloud computing**.

---

### What Does the Word “Cloud” Actually Mean?

#### The word “cloud” is NOT real

There is:
- ❌ No cloud floating in the sky
- ❌ No magical place

The word **cloud** is just a **friendly name**.

---

#### Why did they call it “cloud”?

In old network diagrams:
- The internet was drawn as a **cloud shape**
- Engineers didn’t care *where* exactly the computers were
- They just said: “It’s somewhere on the internet”

So:
- Cloud = **Computers you don’t see**
- Connected via the **internet**

---

#### Important truth

> **The cloud is just someone else’s computer running in a data center.**

---

### Cloud vs Your Laptop vs A Server in a Room

Let’s compare **three things** you already kind of know.

---

### 1. Your Laptop

#### What is it?

- A computer **you own**
- Sitting **on your desk**
- You control everything

---

#### What can your laptop do?

- Run apps
- Store files
- Run code
- Act as a small server (sometimes)

---

#### Limitations of your laptop

- ❌ If it shuts down → everything stops
- ❌ Limited power (CPU, RAM, storage)
- ❌ Only works well for **one user**
- ❌ Not online 24/7
- ❌ If it breaks → data may be lost

---

#### Summary

Your laptop is:
- Personal
- Limited
- Not reliable for big apps or businesses

---

### 2. A Server in a Room

Before cloud existed, companies did this.

---

### What is a server?

A **server** is just:
- A powerful computer
- Meant to run **all the time**
- Serves many users

---

#### How companies used servers earlier

They would:
- Buy servers
- Put them in a room
- Add:
  - Cooling
  - Power backup
  - Internet connection
- Hire people to manage them

This room is called a **server room** or **data center**

---

#### Problems with this approach

- ❌ Very expensive
- ❌ Hard to scale (need more servers? buy new ones)
- ❌ Needs maintenance
- ❌ Needs security
- ❌ If server dies → website/app dies

---

#### Example

If your website suddenly becomes popular:
- Server crashes
- Users can’t access your site
- You lose money

---

### 3. Cloud (Modern Way)

Now comes cloud computing.

---

#### What is cloud computing in practice?

Instead of:
- Buying servers
- Managing hardware
- Maintaining data centers

You:
- **Rent servers over the internet**
- Pay only for what you use
- Scale up or down easily

---

#### Where are these cloud computers?

In **huge data centers** owned by companies like:
- Amazon (AWS)
- Google (GCP)
- Microsoft (Azure)

These data centers have:
- Thousands of servers
- Redundant power
- High security
- 24/7 monitoring

---

#### What YOU see as a developer

You just:
- Click buttons
- Run commands
- Deploy code

No physical server touching. Ever.

---

#### Cloud vs Laptop vs Server Room

| Feature | Laptop | Server in Room | Cloud |
|------|------|------|------|
| Ownership | You | Company | Cloud provider |
| Cost | One-time | Very high | Pay-as-you-use |
| Scaling | Impossible | Hard | Very easy |
| Maintenance | You | You | Provider |
| Reliability | Low | Medium | Very high |
| Internet based | Optional | Yes | Yes |

---

#### Why Did Companies Move to the Cloud?

This is **the most important question**.

---

### Reason 1: Cost

#### Old way
- Buy expensive servers
- Pay upfront
- Even if unused

#### Cloud way
- Pay only when you use
- Stop paying when you don’t
- No upfront cost

---

### Reason 2: Scaling

#### Without cloud

- Traffic increases → server crashes
- Need to buy new servers
- Takes weeks/months

#### With cloud

- Traffic increases → add more servers instantly
- Traffic decreases → remove servers
- Happens in minutes

---

### Reason 3: Reliability

Cloud providers:
- Have backups
- Multiple data centers
- Automatic failover

If one server dies:
- Another one takes over
- Users don’t even notice

---

### Reason 4: Speed of Development

Developers can:
- Launch apps quickly
- Experiment
- Delete and recreate systems easily

No waiting for hardware.

---

### Reason 5: Focus on Business, Not Hardware

Companies want to:
- Build products
- Improve features
- Serve customers

They don’t want to:
- Fix servers
- Manage cables
- Worry about power cuts

Cloud handles all that.

---

### A Simple Mental Model

Remember this forever:

> Cloud computing = Renting powerful computers + storage + services over the internet

You:
- Don’t own them
- Don’t see them
- Don’t manage hardware
- Just **use** them
